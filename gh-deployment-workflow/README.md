# Github Deployment Workflow

This project demonstrates Continous Integration and Continuous Deployment (CI/CD) using Github Actions.

Whenever the `index.html` file is changed and pushed to the `main` branch, a Github Actions workflow automatically deploys the website to GitHub Pages.

## Technologies

-HTML
-Github Actions
-GitHub Pages

## Workflow

1. Developer modifies `index.html`.
2. Changes are pushed to the `main` branch.
3. Github Actions detects the  change.
4. The workflow deploys the website.
5. The updated website becomes available through GitHub Pages.
